# mbgR
Code availability of paper "Positive glacial regulatory processes promote sustainability of Asian glacier water resources"

It is glacier surface mass balance component of glacier evolution model, a retrofit of mass balance gradient model, which developed by Kraaijenbrink et al.

To determine glacier projetion, glacier surface mass balance model outputs should be input to drive PISM ([Parallel Ice Sheet Model](https://www.pism.io)).

The parameteration scheme has been involved in orginal paper's supplementary information.
